# Design System: Свой Сервис

**Источник:** `tailwind.config.ts` + `app/globals.css` — этот файл
только описывает то, что уже реализовано в коде, ничего не добавляет
от себя. При расхождении верить коду, не этому файлу, и поправить файл.

## 1. Visual Theme & Atmosphere

Тёмная «трейд»-премиум эстетика на светлой основе: страница в основном
светлая (белый / `mist-50`), но ключевые секции доверия и конверсии
(Hero, «Почему нам доверяют», CTA-полоса, подвал) — почти чёрные, с
оранжевым акцентом. Не корпоративно-стерильно, не кричаще —
инструментальная, спокойная плотность, крупные тач-зоны (аудитория
30–70 лет).

## 2. Color Palette & Roles

* **Ink 950** (`#0b0e14`) — фон тёмных секций (Hero, Advantages,
  CtaStrip, Footer). Почти чёрный, не насыщенно-синий.
* **Brand 500–700** (`#3466f6` / `#1c60f5` / `#1546d0`) — синий,
  используется на светлом фоне: иконки, ссылки, бейджи, primary text
  accents
* **Brand 50–200** (`#eef4ff` / `#dbe6ff` / `#bed3ff`) — светлые
  бейджи-подложки под иконками на белых карточках
* **Accent** (`#ea580c`, светлее `#f2740f`, темнее `#d24a06`) —
  единственный «горячий» цвет: кнопка заявки, CTA, ничего больше.
  Не размножать на некритичные элементы.
* **Ink 400/500/700/900** — текст на светлом фоне (серо-синие
  нейтральные, не чистый чёрный)
* **Mist 50/100/200** (`#f7f9fc` / `#eef2f9` / `#e2e8f3`) — светлые
  фоны секций-подложек и полей ввода
* **Line** (`#e1e7f2`) — все бордеры на светлом фоне

## 3. Typography Rules

* **Заголовки:** Manrope (`--font-display`), через `next/font/google`,
  самохостинг — экстражирный вес (`font-extrabold`/`font-bold`),
  `text-wrap: balance`
* **Текст:** Inter (`--font-body`)
* **Эйебrow-метки** (`section-eyebrow`): `text-sm font-semibold
  uppercase tracking-[0.14em]`, синий на светлом фоне / оранжевый на
  тёмном
* **section-title:** `text-[1.75rem] sm:text-4xl font-extrabold`
* Никаких декоративных шрифтов сверх этих двух

## 4. Component Stylings

* **Кнопки** (`.btn`): `min-height: 3rem` (48px — тач-зона под
  возрастную аудиторию), `rounded-xl`
  * `.btn-primary` — градиент `#f2740f → #ea580c → #d24a06`, лёгкий
    подъём (`-translate-y-0.5`) на hover, `shadow-cta`
    (`0 8px 24px -10px rgba(234,88,12,.6)`) на конверсионных местах
  * `.btn-secondary` — белый фон, `ring-1 ring-line`
  * `.btn-ghost-light` — для тёмных секций: `bg-white/10 ring-white/25`
* **Карточки** (`.card`): `rounded-2xl border border-line bg-white`
  * `.card-hover` — добавляет подъём + `shadow-lift` на hover
* **Инпуты:** `h-12 rounded-xl border-line bg-mist-50`, фокус —
  `ring-4 ring-brand-500/12` + смена фона на белый
* **Карусели** (`components/Carousel.tsx`): горизонтальный
  scroll-snap, карточка у края обрезана (peek) — подсказка, что список
  длиннее экрана; автопрокрутка только пока карусель видна на экране
  (IntersectionObserver, порог 40%), пауза при hover/touch/focus,
  уважает `prefers-reduced-motion`

## 5. Layout Principles

* `.container-x`: `max-w-6xl`, паддинги `px-5 sm:px-6 lg:px-8`
* `.section`: вертикальный ритм `py-16 sm:py-24`
* Тёмные и светлые секции чередуются, не идут подряд больше двух раз —
  создаёт ритм страницы, помогает ориентироваться при скролле

## 6. Design System Notes for Stitch Generation

**Копировать этот блок в каждый промпт Stitch, если используете Loop:**

**DESIGN SYSTEM (REQUIRED):**
- Platform: Web, отзывчивый (mobile-first), одна длинная страница
- Theme: чередование светлых секций (белый/`#f7f9fc`) и тёмных
  (`#0b0e14`, почти чёрный — НЕ насыщенно-синий, НЕ чёрно-фиолетовый)
- Background (светлые секции): белый / `#f7f9fc`
- Background (тёмные секции): `#0b0e14`
- Primary Accent: оранжевый `#ea580c` — ТОЛЬКО на кнопках заявки/CTA,
  нигде больше
- Secondary Accent: синий `#1c60f5` — иконки, ссылки, бейджи на
  светлом фоне
- Text Primary (светлый фон): `#151d33` (не чистый чёрный)
- Text Primary (тёмный фон): белый / `rgba(255,255,255,.7-.9)`
- Font: заголовки Manrope extrabold, текст Inter, без декоративных
  шрифтов
- Layout: крупные тач-зоны (мин. 48px кнопки), много воздуха,
  скруглённые углы (`rounded-xl`/`rounded-2xl`), карточки с тонкой
  границей вместо тяжёлых теней
- Аудитория: 30–70 лет — крупный читаемый текст, минимум décor, ничего
  мелкого/убористого

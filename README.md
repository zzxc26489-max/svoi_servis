# Свой Сервис

Сайт-лендинг для приёма заявок на ремонт бытовой техники (холодильники,
стиральные и посудомоечные машины, а также другая техника). Заявки с формы
на сайте приходят прямо в Telegram.

## Стек

- [Next.js 14](https://nextjs.org/) (App Router) + React + TypeScript
- Tailwind CSS
- API-роут `/api/order`, который отправляет заявку в Telegram-бота

## Быстрый старт

```bash
npm install
cp .env.example .env.local   # заполните переменные, см. ниже
npm run dev
```

Сайт будет доступен на http://localhost:3000

## Настройка Telegram-бота (куда приходят заявки)

1. В Telegram напишите **@BotFather**, отправьте `/newbot` и следуйте
   инструкциям — получите `TELEGRAM_BOT_TOKEN`.
2. Узнайте свой `chat_id`: напишите боту **@userinfobot**, он пришлёт ваш
   ID в ответ.
3. Обязательно напишите **своему новому боту** любое сообщение (например
   "старт") — иначе он не сможет писать вам первым.
4. Впишите оба значения в `.env.local`:

   ```
   TELEGRAM_BOT_TOKEN=123456:AA...
   TELEGRAM_CHAT_ID=123456789
   ```

Если вы хотите, чтобы заявки приходили не лично вам, а в группу/канал —
добавьте бота туда администратором и укажите ID группы (она начинается с
`-100...`) в `TELEGRAM_CHAT_ID`.

## Переменные окружения

Смотрите `.env.example`:

- `TELEGRAM_BOT_TOKEN` — токен бота
- `TELEGRAM_CHAT_ID` — куда слать заявки
- `NEXT_PUBLIC_CONTACT_TELEGRAM` — ссылка на Telegram для связи
- `NEXT_PUBLIC_SITE_URL` — адрес сайта после деплоя (для микроразметки
  schema.org, необязательно)

## Данные компании (адрес, телефоны, часы работы)

Название, адрес, часы работы и телефоны мастеров хранятся в одном месте —
`lib/business.ts`. Эти значения **должны дословно совпадать** с карточкой
на Яндекс.Картах («Много Техники», Жилинская ул., 13, стр. 1, рп.
Андреевка) — совпадение имени/адреса/телефона (NAP) важно и для доверия
клиентов, и для локального SEO. Меняете что-то на Яндекс.Картах — не
забудьте поправить и здесь.

## Что нужно донастроить перед запуском в бой

- [ ] Заполнить `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID`
- [ ] Указать реальный `NEXT_PUBLIC_CONTACT_TELEGRAM`
- [ ] После деплоя вписать `NEXT_PUBLIC_SITE_URL`
- [ ] При желании — добавить свои логотип/цвета в `tailwind.config.ts`
- [ ] Подключить домен и задеплоить (проще всего — на
      [Vercel](https://vercel.com), бесплатный тариф подходит для старта)

## Деплой на Vercel

1. Залейте репозиторий на GitHub (уже сделано).
2. Зайдите на vercel.com → New Project → выберите этот репозиторий.
3. В настройках проекта добавьте те же переменные окружения, что и в
   `.env.local`.
4. Нажмите Deploy — через пару минут сайт будет на своём поддомене
   `*.vercel.app`, к которому потом можно привязать свой домен.

## Структура проекта

```
app/
  page.tsx           — главная страница (сборка всех секций)
  layout.tsx         — общий layout, метаданные (SEO)
  api/order/route.ts — приём заявок и отправка в Telegram
components/          — секции лендинга (Hero, Services, форма и т.д.)
lib/telegram.ts      — работа с Telegram Bot API
lib/business.ts      — адрес, часы работы, телефоны мастеров (сверять с Я.Картами)
lib/structuredData.ts — микроразметка schema.org для поисковиков
```

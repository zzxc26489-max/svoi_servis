### Бизнес-модель

Владелец принимает заявки и распределяет их: часть чинит сам, часть отдаёт
проверенным партнёрским мастерским за процент. Работает с несколькими
конторами, условия по каждой отличаются. Нанимать сотрудников на оклад
планирует только когда поток заявок станет стабильным.

Конкретные проценты по партнёрам в этот файл не пишем — репозиторий
публичный.

**На сайте передачу партнёрам нигде не упоминаем** — ни как факт, ни
как формулировку «передаём проверенным мастерским». Если клиент
узнает, что часть техники чинят не «свои» мастера, он может обратиться
к партнёру напрямую и уйти в обход. Другую технику на сайте принимаем
формулировкой «уточним после заявки» — без объяснения, кто именно
будет чинить.

### Страницы

| Путь | Файл | Зачем |
|---|---|---|
| `/` | `app/page.tsx` | Вся воронка одним экраном-скроллом |

Основную воронку намеренно **не** разбиваем на страницы: каждый лишний
клик — это отвал, а порядок секций на главной уже работает как воронка
(оффер → что чиним → цены → как проходит → работы → отзывы → цифры
доверия → форма → вопросы → CTA). Отдельные страницы заводим только под
то, что растёт само и тянет свой трафик из поиска — как архив работ.
Архив обязан возвращать в воронку: внизу у него форма заявки и ссылка
на прайс.

Ссылки в шапке — вида `/#services` через `next/link`, а не голый
`#services`: со второй страницы якорь без пути никуда не ведёт.

### Живой статус работы (`WorkStatus.tsx` + `lib/workingHours.ts`)

Бейдж «Сейчас работаем. Принимаем заявки сегодня до 22:00» в первом
экране и в секции заявки. Вне рабочих часов — «Заявку можно оставить в
любое время — перезвоним, как только сможем».

Два правила, которые легко нарушить при правке:
- **Часы считаем по времени мастерской** (`BUSINESS.timeZone`), а не по
  часовому поясу устройства — иначе клиент с неверно настроенным
  телефоном увидит «закрыто», когда мастер на связи
- **Никаких формулировок-отказов в нерабочие часы.** Форма принимает
  заявку круглосуточно; ночная поломка — повод оставить номер, а не
  услышать «приходите в рабочее время»

Считается только в браузере (`useSyncExternalStore`): страница
отдаётся статикой, время сборки к моменту открытия отношения не имеет.

### Форма заявки (`QuickLeadForm.tsx`)

Главное решение: **только номер телефона**, больше ничего. Владелец убрал
все поля после того, как заметил, что клиенты отваливаются на середине
формы.

Тихий захват брошенного ввода: если человек дописал номер до 11 цифр, но
не нажал кнопку, через 1,5 секунды тишины номер уходит в Telegram сам, с
пометкой 🟡. Идея взята из ролика про рост закрытых заявок — человек мог
отвлечься, а заявка уже не потеряется.

**Чекбокс согласия обязателен** и не отмечен по умолчанию: Роскомнадзор
не признаёт согласием ни предзаполненную галочку, ни фразу «нажимая
кнопку, вы соглашаетесь». Тихий захват тоже под ним — без галочки номер
не уходит вообще, иначе мы бы отправляли ПДн без согласия.

**Галочка стоит выше поля телефона** — это не случайность: тихий захват
срабатывает только при отмеченном согласии, поэтому человек должен
успеть отметить его до того, как впишет номер. Если переставить
галочку под поле, фича перестанет работать для большинства.

Состояния ошибок разведены:
- `invalid` — номер недописан, виноват ввод
- `consent` — номер верный, но согласие не отмечено
- `failed` — номер верный, но отправка не сработала. Показываем прямой
  телефон мастера, клиента не виним

### Технические решения

- Next.js 16 (App Router), TypeScript, Tailwind CSS
- Шрифты: Manrope (заголовки) + Inter (текст) через `next/font` —
  самохостинг, без внешних запросов
- Общая карусель (`Carousel.tsx`) — «Услуги», «Работы», «Отзывы»: едет
  сама, пока её не трогают (пауза при наведении/касании/фокусе,
  уважает `prefers-reduced-motion`), прокручивается вручную свайпом,
  стрелками или клавиатурой; следующая карточка видна не целиком —
  подсказка, что список длиннее экрана
- Все данные компании в одном месте: `lib/business.ts`
- `lib/basePath.ts` → `withBasePath()` для `src` картинок: на превью
  GitHub Pages сайт живёт в подпути, а `next/image` с
  `unoptimized` (обязателен для статического экспорта) сам его НЕ
  подставляет — забыть про это = битые фото на превью
- Фото в галерее «Работы» — формат WebP (легче JPEG) + блюр-превью
  (`blurDataURL` в `WORKS`), чтобы при открытии страницы не было
  пустых прямоугольников — сразу видно размытый эскиз, затем чёткое
  фото
- Микроразметка schema.org: `lib/structuredData.ts` — LocalBusiness с
  рейтингом (везде), FAQPage (в `Faq.tsx`), BreadcrumbList (на `/works`)
- `/sitemap.xml`, `/robots.txt`, `/llms.txt` — `app/sitemap.ts`,
  `app/robots.ts`, `app/llms.txt/route.ts`. Все три требуют `export
  const dynamic = "force-static"`, иначе статический экспорт для
  GitHub Pages падает на сборке. `robots.txt` уважает
  `NEXT_PUBLIC_PREVIEW` — превью на GitHub Pages не индексируется
- Заявки уходят в Telegram: `app/api/order/route.ts` + `lib/telegram.ts`
- Иконки: свои SVG в `components/icons.tsx`, эмодзи не используем

## 7. Как работать с этим проектом

Принципы разработки — в `CLAUDE.md`. Коротко:

### Stitch Loop (генерация дизайна через Google Stitch)

Скилл `.claude/skills/stitch-loop/` (из `google-labs-code/stitch-skills`,
проверен — только markdown, без сетевых вызовов) + конфиг с реальными
данными проекта: `.stitch/SITE.md` (миссия, аудитория, воронка, роадмап)
и `.stitch/DESIGN.md` (палитра/шрифты/компоненты — транскрипция
`tailwind.config.ts`, не выдумка).

**Важно:** сайт — не мультистраничный статический HTML, а Next.js с
компонентами-секциями. `.stitch/SITE.md` §0 объясняет, как использовать
Stitch-генерации как референс вёрстки одной секции, а не как готовый
файл для заливки. Для реального запуска нужен подключённый Stitch MCP
Server — в этой сессии его нет.

Проверка перед сдачей:

```bash
npm run lint && npm run build
```

Скриншоты через Playwright (браузер уже стоит):

```bash
NODE_PATH=/opt/node22/lib/node_modules node -e "
const { chromium } = require('playwright');
(async () => {
  const b = await chromium.launch({ executablePath: '/opt/pw-browsers/chromium' });
  const p = await b.newPage({ viewport: { width: 1440, height: 900 } });
  await p.goto('http://localhost:3000/', { waitUntil: 'networkidle' });
  await p.screenshot({ path: '/tmp/shot.png' });
  await b.close();
})();
"
```
